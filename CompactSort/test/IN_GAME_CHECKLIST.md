# 游戏内验收清单

自动测试只覆盖 `src/Packing/` 的纯算法。以下路径依赖 Unity 运行时，**发布前必须按顺序走一遍**，并在最后记录结果。

## 0.0 F8 只读自检（先跑这个）

- [ ] 进入店内，按 `F8`
- [ ] 日志出现 `[CompactSort][TEST] SUMMARY pass=N fail=0`
- [ ] `global_pool_disabled`、`per_container_disabled` 为 PASS
- [ ] 失败时先看 `FAIL case=...`，不要继续后面的破坏性操作
- [ ] WSL 下可运行 `python3 test/ingame/check_selftest.py`，返回 0 才算通过

自检不移动任何物品；它检查展示柜/垃圾桶/柜台是否被排除、暗格是否被允许、容器是否重叠/越界。

## 0. 准备

- [ ] 完全退出游戏后再覆盖 DLL，确认安装目录版本与 `manifest.xml` 一致
- [ ] 备份存档：复制 `%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen` 整个目录
- [ ] 清空/备份旧 `Player.log`
- [ ] 进入游戏后确认模组已启用、没有注入/扫描报错

日志：

```
C:\Users\<user>\AppData\LocalLow\Questing Goose Studio\Probably Stolen\Player.log
```

关键前缀：`[CompactSort]`。

## 1. 右键菜单与原版隔离

- [ ] 右键容器空白处，菜单仍有原版 4 个排序按钮
- [ ] 第 5 个是“紧凑整理”，位于原版 4 个按钮下方、撤销上方
- [ ] 点原版“大件优先”仍然走原版行为，不被本模组替换
- [ ] 点“紧凑整理”后有布局变化，整理后重新打开菜单，“撤销”可用
- [ ] 低占用容器（<80%）整理后，日志可出现 `visual-first layout selected`
- [ ] 同 identifier 物品尽量成行/成块，且优先从上到下、从左到右
- [ ] 高占用容器仍优先保持紧凑；visual-first 放不下时回退 Hybrid
- [ ] 撤销后物品数量、形状、位置回到整理前

## 2. 锁定排序

- [ ] 悬停物品按 `Ctrl+Q`（或右键 Pin）显示“锁定排序”
- [ ] 锁定后执行“紧凑整理”和拖拽补位，该物品位置/形状完全不变
- [ ] 再按 `Ctrl+Q` 解锁，之后可以被整理移动
- [ ] 锁定物品所在容器仍能整理其他物品，不会整体跳过（除非只有锁定物品）

## 3. 拖拽自动补位（重点：物品守恒）

- [ ] 目标容器留出接近满的空间，拖入 1 件放不下的物品
- [ ] 拖拽结束后目标容器自动重排，拖入的物品进入目标容器
- [ ] 记录拖拽前后：源容器物品数 + 目标容器物品数，必须完全一致
- [ ] 目标容器原有物品没有被销毁、复制或改数量
- [ ] 逐个检查物品没有两件占同一格（包括看起来“叠在一起”的不同层）
- [ ] 对多选拖拽重复一次
- [ ] 若失败/回滚，日志有 `drag`/`rollback`，且物品仍在原容器，不能出现“消失”

## 4. 全局池整理（已禁用）

- [ ] 按 `Ctrl+R` 没有任何整理反应
- [ ] 日志不出现 `[CompactSort] global pool:` 或 `global pool: disabled`
- [ ] 设置 → 紧凑整理锁定键 里没有“全局池整理按键”
- [ ] 右键“紧凑整理”仍然只处理当前容器，不跨容器搬物品

## 5. 逐容器快捷键（已禁用）

- [ ] 按 `Ctrl+Shift+R` 没有任何整理反应
- [ ] 日志不出现 `full sort:` 或 `full sort: disabled`
- [ ] 设置里没有“逐容器整理按键”
- [ ] 逐容器整理只能通过每个容器右键“紧凑整理”手动执行

## 6. 展示柜 / 垃圾桶 / 桌面 / 暗格（重点：边界）

- [ ] 展示柜、垃圾桶、前台/后台/内部柜台桌面内放标记物品，**拖拽另一件物品进入**，应触发补位且物品守恒
- [ ] 上述容器中 `Ctrl+R` / `Ctrl+Shift+R` 仍不触发全池/逐容器整理
- [ ] 快捷键无反应，标记物品仍在原处
- [ ] 在垃圾桶的走私者暗格内放标记物品，执行右键“紧凑整理”/拖拽补位
- [ ] 暗格参与手动紧凑整理/拖拽；标记物品数量守恒，不能消失
- [ ] 暗格外层的垃圾桶本身可拖拽补位，但不会被全局池/自动收集卷入
- [ ] 手动打开暗格，右键“紧凑整理”仍然可用
- [ ] 打开一个带内容窗口的容器物品，确认自动整理只处理窗口直接子容器，不递归内部嵌套容器

## 7. 重叠回归（子弹 / 核废料）

- [ ] 准备 1x1 子弹和 1x1 核废料，故意放到同一区域
- [ ] 执行“紧凑整理”/拖拽补位
- [ ] 两者不能出现在同一格；日志无 `overlap detected`
- [ ] 若日志出现 `overlap detected ... rolling back`，布局必须回滚，不能留半成品

## 8. 自动快照

- [ ] 睡一次（进入新一天）后，`CompactSortSnapshots` 目录出现 `snapshot-day-*.json`
- [ ] 文件包含仓库/主背包/柜台/展示柜/垃圾桶/暗格等容器
- [ ] 再次睡眠后新增一份，不覆盖旧文件
- [ ] `python3 test/ingame/check_snapshots.py` 全部 PASS
- [ ] `analysis/global_bench/run.sh --snapshot <目录>` 能读取并输出 CSV
- [ ] 快照过程不改变物品位置/数量
